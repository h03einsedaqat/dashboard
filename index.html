لایه سرویس: جایی که دمو به محصول تبدیل می‌شود

هیچ صفحه‌ای داده را مستقیم نمی‌خواند. هر درخواست از `src/services/*.service.js` رد می‌شود، پس وصل‌کردن بک‌اند یعنی تغییر `config.api` — بدون دست‌زدن به HTML، بدون بازنویسی کامپوننت‌ها.

  • حالت mock و حالت API با یک کلید روشن/خاموش می‌شوند
  • خطا، timeout و retry یک‌جا تعریف شده‌اند (ApiError)
  • state سراسری: تم، زبان، چیدمان و جستجو در همه صفحه‌ها مشترک است
  • هر بلوک UI مستقل است؛ کم‌کردن یک بخش، بقیه را نمی‌شکند
