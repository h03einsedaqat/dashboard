بسته تحویل — نسخه ۱٫۰٫۰

از این‌جا شروع کنید

این بسته شامل خروجی آماده انتشار (html/)، سورس کامل (source/)، مستندات (documentation/)، دارایی‌ها (assets/) و پیش‌نمایش‌ها (screenshots/) است. اگر فقط می‌خواهید قالب را ببینید، همین حالا صفحه محصول را باز کنید؛ بدون نصب، بدون ابزار.

۲۰۶ صفحه مستقل ۱۰ داشبورد ۶ چیدمان ۳ زبان تقویم شمسی RTL و LTR بدون jQuery

۱) سریع‌ترین راه: تماشا

خروجی آماده بدون هیچ ابزاری کار می‌کند:

html/index.html                              ← صفحه محصول
html/dashboards/analytics.html               ← داشبورد آنالیتیکس
html/preview.html                            ← پیش‌نمایش زنده (تغییر تم و چیدمان)
html/ai/chat.html                            ← کارگاه هوش مصنوعی
html/docs/introduction.html                  ← مستندات داخل قالب

همه لینک‌ها نسبی هستند؛ اگر کل پوشه را در زیرپوشه‌ای روی هاست بگذارید، بدون تغییر کار می‌کند.

انتشار روی هاست: تمام محتوای html/ را در ریشه دامنه یا زیرپوشه آپلود کنید. تمام — بدون مرحله دیگر.

۲) کار روی سورس

برای تغییر رنگ، صفحه یا منطق، از پوشه source/ استفاده کنید:

cd source
npm install
npm run dev        # http://localhost:5173
npm run build      # خروجی در dist/
npm run qa:all     # ساخت + کنترل لینک‌ها + تست اجرای صفحه‌ها

پوشه source/ شامل node_modules نیست؛ اجرای npm install الزامی است. Node.js نسخه ۱۸ یا بالاتر لازم است.

۳) نقشه بسته

novaadmin-1.0.0/
├── START-HERE.html      ← همین فایل
├── README.md            ← معرفی کامل قالب
├── CHANGELOG.md         ← تاریخچه تغییرات
├── LICENSE.txt          ← شرایط مجوز
├── html/                ← سایت آماده انتشار
├── source/              ← سورس، ابزارها و تنظیمات
├── documentation/       ← ۲۳ موضوع مستند (مارک‌داون)
├── assets/              ← فونت، تصویر و فایل‌های برداری
└── screenshots/         ← پیش‌نمایش‌های برداری

فایل‌های توسعه‌ای (node_modules، .git، ابزارهای تست) عمداً در بسته نیستند.

۴) اولین تغییرات پیشنهادی

می‌خواهم…فایل
نام و شعار محصول را عوض کنمsource/src/config/config.js
لوگو و آیکن را عوض کنمsource/public/assets/logo*.svg
رنگ سازمانی اضافه کنمsource/src/scss/base/_palettes.scss
صفحه جدید بسازمsource/tools/manifest.mjs → npm run gen:pages
داده نمونه را واقعی کنمsource/src/data/*.js
به API خودم وصل شومsource/src/config/config.js → api.useMocks = false
متن‌های رابط را ترجمه کنمsource/src/locales/{fa,en,ar}.js

۵) مسیر یادگیری

  1. نصب و راه‌اندازی — پوشه‌ها، اسکریپت‌ها و اجرای پروژه
  2. ساختار پروژه — چه چیزی کجاست و چه چیزی تولیدشده است
  3. تنظیمات — برند، زبان، ارز، تقویم و اتصال API
  4. شخصی‌سازی تم — توکن‌ها، پالت‌ها و حالت تاریک
  5. افزودن صفحه جدید — منیفست، کنترل‌کننده، بدنه اختصاصی
  6. اتصال به API — قرارداد REST و سرویس‌های آماده
  7. استقرار — هاست، زیرپوشه، کش و هدرها
  8. رفع اشکال — پاسخ مشکلات رایج پیش از تماس با پشتیبانی

نسخه قابل مرور همین مستندات با جستجو، فهرست کنار صفحه و بلوک‌های کد در قالب هم موجود است: مستندات درون قالب.
