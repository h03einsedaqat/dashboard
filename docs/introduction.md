# معرفی

NOVAADMIN یک قالب پنل مدیریت چندمنظوره و **فارسی‌محور** است که با HTML5، SCSS، ماژول‌های ES2022 و Vite ساخته شده. هر صفحه یک فایل HTML مستقل است؛ هیچ فریم‌ورک جاوااسکریپتی مثل React/Vue در کار نیست و هیچ بک‌اندی لازم ندارید.

> نکته: هدف این قالب «نمونه اولیه سریع» نیست؛ یک سیستم طراحی کامل با توکن، تم روشن/تاریک/سیستم، شش تم رنگی، RTL و LTR هم‌سطح، تقویم شمسی و ۲۰۶ صفحه آماده است.

## چه چیزی داخل جعبه است؟

- **۶ چیدمان** — سایدبار پیش‌فرض، مینی، جمع‌شده، افقی، دو ستونی و باکس‌دار
- **۱۰ داشبورد تخصصی** — آنالیتیکس، فروشگاهی، CRM، SaaS، مالی، پروژه‌ها، منابع انسانی، پشتیبانی، هوش مصنوعی و لجستیک
- **کارگاه هوش مصنوعی** — چت، نویسنده، خلاصه‌ساز، بازتولید محتوا، کتابخانه پرامپت، استودیو تصویر، زمان‌بند، مصرف، مدل‌ها و کلیدهای API
- **ماژول‌های سازمانی** — کاربران و نقش‌ها، فروشگاه، CRM، پروژه و وظایف، کانبان، تقویم، ایمیل، گفتگو، فایل‌ها، تیکت‌ها، CMS و مالی
- **۲۳ مستند** (همین بخش)، صفحات خطا، صفحات بازاریابی، UI Kit و **۲۰۰+ صفحه** قابل استفاده
- **لایه داده شبیه‌سازی‌شده** — `src/services/*` با همان قرارداد REST تا اتصال به API واقعی فقط یک فایل را تغییر دهد

## برای چه کسی مناسب است؟

| مخاطب | استفاده |
| --- | --- |
| تیم محصول | راه‌اندازی سریع پنل داخلی با ظاهر حرفه‌ای و پشتیبانی فارسی |
| توسعه‌دهنده فرانت‌اند | سیستم طراحی آماده، کامپوننت‌های مستند و ساختار ماژولار |
| آژانس‌ها | تحویل سریع به مشتری با تم اختصاصی و زبان‌های fa/en/ar |
| توسعه‌دهنده بک‌اند | فرانت آماده که فقط به API شما وصل می‌شود |

## معماری در یک نگاه

```text
index.html            صفحه محصول
src/pages/**          ۲۰۶ صفحه تولیدشده (پوسته + محتوا)
src/partials/**       قطعه‌های مشترک (head، هدر، فوتر، پاپ‌آپ‌ها، پیام‌ها)
src/scss/**           توکن‌ها، تم‌ها، کامپوننت‌ها و لایه‌های چیدمان
src/js/core/**        هسته: تم، چیدمان، جدول داده، نمودار، تقویم، کانبان…
src/js/pages/**       کنترل‌کننده هر بخش (داشبوردها، ماژول‌ها، AI، اپلیکیشن‌ها…)
src/services/**       لایه داده (شبیه‌سازی REST با تأخیر واقعی)
src/data/**           داده نمونه واقع‌گرایانه
src/locales/**        دیکشنری فارسی، انگلیسی و عربی
tools/**              ابزارهای ساخت، تولید دارایی‌ها، کنترل کیفیت و بسته‌بندی
docs/**               منبع مارک‌داون همین مستندات
```

> هدف: هر فایل یک مسئولیت داشته باشد. اگر برای تغییر یک رفتار مجبور شدید دو جا را ویرایش کنید، ساختار را نقض کرده‌اید.
