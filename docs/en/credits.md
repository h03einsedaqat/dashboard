## Image assets

All template images are generated as **custom vector graphics (SVG)**; there are no stock photos or copied icons in the package:

| Set | Count | Generated by |
| --- | --- | --- |
| Logo and mark | 4 | `tools/gen-assets.mjs` |
| User avatars | 24 | `tools/gen-assets.mjs` |
| Product images | 24 | `tools/gen-assets.mjs` |
| Brand logos | 12 | `tools/gen-assets.mjs` |

These files match the template palette and look right in dark mode too. To replace them, just swap the files with the same names in `public/assets/img/`.
