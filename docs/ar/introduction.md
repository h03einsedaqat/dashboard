# مقدمة

NOVAADMIN قالب لوحة إدارة متعدد الأغراض **يضع الفارسية أولاً**، مبني بـ HTML5 وSCSS ووحدات ES2022 وVite. كل صفحة ملف HTML مستقل؛ لا يوجد أي إطار عمل جافاسكريبت مثل React/Vue، ولا تحتاج إلى أي واجهة خلفية.

> ملاحظة: هذا القالب ليس «نموذجاً أولياً سريعاً»؛ بل نظام تصميم متكامل مع رموز تصميم، وسمات فاتحة/داكنة/حسب النظام، وست سمات لونية، ودعم متكافئ لـ RTL وLTR، وتقويم هجري شمسي و٢٠٦ صفحات جاهزة.

## ماذا يوجد داخل الحزمة؟

- **٦ تخطيطات** — الشريط الجانبي الافتراضي، المصغّر، المطوي، الأفقي، ذو العمودين والمؤطّر
- **١٠ لوحات متخصصة** — التحليلات، المتجر، CRM، SaaS، المالية، المشاريع، الموارد البشرية، الدعم، الذكاء الاصطناعي واللوجستيات
- **ورشة الذكاء الاصطناعي** — الدردشة، الكاتب، الملخِّص، إعادة صياغة المحتوى، مكتبة الموجّهات، استوديو الصور، المجدول، الاستهلاك، النماذج ومفاتيح API
- **الوحدات المؤسسية** — المستخدمون والأدوار، المتجر، CRM، المشاريع والمهام، كانبان، التقويم، البريد، الدردشة، الملفات، التذاكر، CMS والمالية
- **٢٣ موضوعاً توثيقياً** (هذا القسم)، وصفحات الأخطاء، وصفحات التسويق، وUI Kit و**أكثر من ٢٠٠ صفحة** قابلة للاستخدام
- **طبقة بيانات محاكاة** — `src/services/*` تتبع عقد REST نفسه، فيقتصر الربط بـ API حقيقي على تعديل ملف واحد

## لمن هو مناسب؟

| الجمهور | الاستخدام |
| --- | --- |
| فرق المنتج | إطلاق سريع للوحة داخلية بمظهر احترافي ودعم للفارسية |
| مطوّرو الواجهة الأمامية | نظام تصميم جاهز، ومكونات موثقة، وبنية معيارية |
| الوكالات | تسليم سريع للعميل بسمة مخصصة ولغات fa/en/ar |
| مطوّرو الواجهة الخلفية | واجهة أمامية جاهزة لا تحتاج إلا إلى الربط بـ API الخاص بك |

## البنية في لمحة

```text
index.html            صفحة المنتج
src/pages/**          ٢٠٦ صفحات مولّدة (الهيكل + المحتوى)
src/partials/**       أجزاء مشتركة (head، الترويسة، التذييل، النوافذ المنبثقة، الرسائل)
src/scss/**           رموز التصميم، السمات، المكونات وطبقات التخطيط
src/js/core/**        النواة: السمة، التخطيط، جدول البيانات، المخططات، التقويم، كانبان…
src/js/pages/**       متحكم لكل قسم (اللوحات، الوحدات، الذكاء الاصطناعي، التطبيقات…)
src/services/**       طبقة البيانات (محاكاة REST بتأخير واقعي)
src/data/**           بيانات نموذجية واقعية
src/locales/**        قواميس الفارسية والإنجليزية والعربية
tools/**              أدوات البناء وتوليد الأصول وضبط الجودة والتحزيم
docs/**               مصدر Markdown لهذه الوثائق
```

> الهدف: أن تكون لكل ملف مسؤولية واحدة. إذا اضطررت إلى تعديل موضعين لتغيير سلوك واحد، فقد أخللت بالبنية.
