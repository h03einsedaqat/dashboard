# استكشاف الأخطاء

كُتب هذا القسم بناءً على مشكلات تحدث فعلاً في مشاريع HTML/Vite. ويتضمن كل بند العَرَض والسبب والحل.

## تُفتح الصفحة بلا أنماط

**العَرَض:** تظهر النصوص بلا ألوان أو مسافات؛ وفي لوحة الشبكة حُمّل ملف SCSS بـ `Content-Type: application/javascript`.

**السبب:** يقدّم Vite ملفات `.scss` في وضع التطوير كوحدات JS ولا يطبّقها المتصفح كأنماط.

**الحل:** يجب أن يحمل رابط الأنماط المعامل `?direct` (في `src/partials/head.html`):

```html
<link rel="stylesheet" href="/src/scss/main.scss?direct">
```

وفي المخرجات النهائية (`npm run build`) يُستبدل هذا الرابط بملف CSS مجزّأ الاسم.

## تعطي الروابط من الصفحات المتداخلة خطأ ٤٠٤

**السبب:** كل صفحة تقع في مجلد أعمق بمستوى؛ لذا يجب أن يكون `users/list.html` من داخل `crm/contacts.html` هو `../users/list.html`.

**الحل:** تُصحَّح الروابط المولّدة وقت التشغيل تلقائياً بـ `src/js/core/links.js` (`fixLinks` + `observeLinks`). وإذا كتبت رابطاً ثابتاً بنفسك:

```html
<a href="{{ROOT}}users/list.html">المستخدمون</a>
```

أو استخدم `NOVA.url('users/list.html')` في جافاسكريبت.

## تظهر الصفحات بعد البناء في `dist/src/pages`

**السبب:** يجب أن تحمل مفاتيح إدخال Vite الامتداد `.html`.

**الحل:** تأكد من وجود `tools/build-pages.mjs` و`tools/flatten-dist.mjs` في سلسلة `npm run build` وأن مرحلة `flatten-dist` هي الأخيرة.

## الفئات التي كتبتها في JS بلا أنماط

**الحل:** نفّذ `npm run qa:links`؛ تقارن هذه الأداة جميع الفئات المستخدمة في HTML وفي قوالب JS بالأنماط الموجودة وتعطي قائمة النواقص.

## بقيت رموز `{{...}}` في HTML المخرجات

**السبب:** أضفت رمزاً جديداً غير موجود في خريطة الرموز في `tools/nova-plugin.mjs`.

**الحل:** أضفه إلى `TOKENS` ونفّذ `npm run build` مجدداً. وللتحقق:

```bash
grep -ro "{{[A-Z_]*}}" dist --include=*.html | sort -u
```

## لا تظهر بيانات الجدول وتُعرض «لم يُعثر على عناصر»

**الأسباب المحتملة:**
1. اسم المورد في `data-resource` لا يطابق مفتاح السجل في `src/services/index.js`.
2. الفلتر الافتراضي صارم؛ اضغط زر «مسح الفلاتر».
3. اسم الحقل غير موجود في `searchFields` للخدمة؛ فأداة البحث تعمل لكنها لا تعيد نتائج.

## تضيع تغييراتي في البناء التالي

**السبب:** تُعاد كتابة ملفات `src/pages/**` في كل بناء.

**الحل:** أجرِ التغيير في `src/partials/pages/<المسار>.html` أو في المتحكم المعني في `src/js/pages/**`.

## لا يُحمَّل الخط الفارسي

**السبب:** يُقرأ الخط من `node_modules/vazirmatn`. وإذا كان `node_modules` ناقصاً، فلن يُعثر على ملف woff2.

**الحل:** نفّذ `npm install` بالكامل. في المخرجات النهائية يوجد الخط في `dist/assets/fonts/`؛ تحقّق من وجوده:

```bash
ls dist/assets/fonts/
```

## يبقى المخطط فارغاً

**الأسباب المحتملة:** حاوية المخطط غير موجودة، أو `data-chart-key` مكرر، أو استُدعي `initCharts` قبل عرض DOM.

**الحل:** استدعِ `initCharts(scope)` بعد العرض. تختبر الأداة `npm run qa:smoke` هذا السلوك نفسه في DOM محاكى وتُظهر الصفحة المعيبة.

## في RTL يخرج شيء عن حافة الصفحة

**السبب:** استخدام `left/right` بدلاً من الخصائص المنطقية.

**الحل:** `left` ← `inset-inline-start`، و`right` ← `inset-inline-end`، و`margin-left` ← `margin-inline-start`، و`border-left` ← `border-inline-start`. ثم اختبر الصفحة في الاتجاهين.

## للصفحة شريط أفقي إضافي على الجوال

**الأسباب الشائعة:** جدول بلا `.table-responsive`، أو عرض ثابت بالبكسل، أو `white-space: nowrap` على نص طويل.

**الحل:** ضع الجداول داخل `.table-responsive`، واكتب العروض بـ `min(100%, …)`، وتعامل مع النصوص الطويلة بـ `text-wrap: pretty` أو بكسر الكلمات. اختبر العروض ٣٢٠/٣٧٥/٤١٤.

## الروتين المتكرر: كيف أجد الخطأ؟

```bash
npm run qa:links     # أخطاء المخرجات (الروابط، الأصول، الفئات، إمكانية الوصول)
npm run qa:smoke     # أخطاء وقت تشغيل المتحكمات
```

تُبلغ الأداتان عن الفشل برمز خروج غير صفري، ويمكنك تشغيلهما في CI أيضاً.

> ملاحظة: إذا رأيت خطأ في وحدة التحكم، فالرسائل تُطبع بالبادئة `[NOVAADMIN]`؛ ضع نص الخطأ واسم الملف في تقريرك.
