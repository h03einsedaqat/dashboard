# الأسئلة الشائعة

## عام

**هل يحتاج إلى واجهة خلفية؟**
لا. جميع الصفحات تعمل ببيانات نموذجية. للربط بـ API حقيقية راجع قسم [الربط بـ API](api-integration.html).

**هل يمكنني استخدام React/Vue أيضاً؟**
القالب مكتوب بـ HTML/CSS/JS خالص. يمكنك تحميل الحزمة داخل مشروع React، لكن الميزة الأساسية للقالب أنه غير مرتبط بإطار عمل.

**كم صفحة يضم؟**
٢٠٦ صفحات مستقلة (١٠ لوحات تحكم، ٧٨ تطبيقاً، ٤٧ جدول قوائم، ٢١ صفحة UI Kit، ٢٣ وثيقة، ١٦ صفحة نظام، ١١ صفحة مصادقة) إضافة إلى صفحة المنتج وصفحة المعاينة.

**هل الخطوط بترخيص حر؟**
نعم. يُوزَّع خط Vazirmatn بترخيص SIL OFL وأيقونات Bootstrap Icons بترخيص MIT. التفاصيل في [الإشادات](credits.html).

## المظهر والسمة

**كيف أضع لون مؤسستي؟**
أنشئ لوحة جديدة في `src/scss/base/_palettes.scss` واضبط `data-primary` عليها. راجع قسم [تخصيص السمة](theme-customization.html).

**كيف أغيّر الشعار؟**
استبدل الملف `public/assets/logo.svg` (والنسخ `logo-dark.svg` و`logo-mark.svg` و`favicon.svg`) بتصميمك؛ ولا تغيّر الأسماء.

**هل يعمل الوضع الداكن لجميع المكونات؟**
نعم. السمة الداكنة مبنية بالرموز لا بإعادة كتابة المكونات؛ لذا يُدعم تلقائياً أي عنصر جديد تبنيه بالرموز.

**كيف أغيّر حجم الخط؟**
من لوحة التخصيص أو بـ `theme.set('fontSize', 'lg')`. منذ الإصدار ١٫١ صار التخطيط والكثافة ونمط القائمة ثابتة على القيم المختبرة وأُزيلت من لوحة التخصيص كي لا يختل الهيكل أبداً.

## البيانات والجداول

**أين أغيّر البيانات؟**
في ملفات `src/data/*.js`. جميعها مبنية من مولّد واحد ببذرة ثابتة (`src/data/rng.js`)؛ لذا فالمخرجات قابلة للتكرار.

**كيف أنشئ جدولاً جديداً؟**
راجع قسم [جداول البيانات](data-tables.html)؛ ينتهي الأمر في بضعة أسطر بـ `data-datatable` و`data-resource`.

**ماذا عن الفلترة والترتيب من جهة الخادم؟**
تُرسَل المعاملات `page` و`perPage` و`search` و`sort` و`order` والفلاتر في الطلب نفسه إلى API؛ ويكفي أن تقبلها الواجهة الخلفية.

## الترجمة والتقويم

**كيف أضيف لغة رابعة؟**
قسم [تعدد اللغات](localization.html) — ملف قاموس واحد وسطر واحد في `index.js`.

**هل تبقى الأرقام فارسية دائماً؟**
في الفارسية نعم. في الإنجليزية تصبح الأرقام لاتينية وفي العربية تصبح هندية عربية، ويتغير الاتجاه أيضاً.

**كيف أفعّل التقويم الميلادي؟**
`theme.set('calendar', 'gregorian')` أو خيار «التقويم» في لوحة التخصيص.

## البناء والنشر

**لماذا يعمل `npm run dev` على المنفذ ٥١٧٣؟**
إنه المنفذ الافتراضي لـ Vite. غيّره بـ `npm run dev -- --port 5180`.

**لماذا لا تُطبَّق الأنماط في وضع التطوير؟**
كُتب رابط الأنماط في `src/partials/head.html` مع `?direct` ليقدّمه Vite كملف CSS. إذا حُذف هذا المعامل، يُقدَّم الملف كوحدة JS وتبقى الصفحة بلا أنماط.

**أين أرفع المخرجات؟**
محتوى `dist/`. راجع قسم [النشر](deployment.html).

**كيف أبني حزمة البيع؟**
`npm run package` — يُنشئ ملف ZIP قياسياً بالمجلدات `html/` و`source/` و`documentation/` و`assets/` و`screenshots/` و`changelog/`.

## الدعم

**هل التحديثات مجانية؟**
مدة الدعم والتحديث موضحة في الملف `LICENSE.txt`.

**كيف أبلّغ عن خطأ؟**
عبر بريد الدعم (`supportEmail` في `src/config/config.js`) مع ذكر الإصدار والمتصفح وخطوات إعادة الإنتاج. قبل الإرسال نفّذ `npm run qa:all` وأرفق النتيجة.

> ملاحظة: قبل طرح السؤال راجع قسم [استكشاف الأخطاء](troubleshooting.html)؛ فإجابة معظم المشكلات الشائعة موجودة هناك.
