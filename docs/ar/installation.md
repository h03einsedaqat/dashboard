# التثبيت

يتطلب تثبيت NOVAADMIN وجود Node.js. إذا كنت تريد فقط وضع **المخرجات الجاهزة** على الاستضافة، فلا تحتاج إلى أي أداة: ارفع مجلد `html/` من حزمة المنتج مباشرة.

## المتطلبات المسبقة

| الأداة | الإصدار | ملاحظات |
| --- | --- | --- |
| Node.js | ١٨ أو أحدث | للبناء وبيئة التطوير فقط |
| npm | ٩ أو أحدث | إدارة الاعتماديات |
| متصفح حديث | Chrome / Edge / Firefox / Safari | يدعم CSS Nesting و`:has()` وES2022 |

## خطوة بخطوة

1. فكّ ضغط ملف ZIP الخاص بالمنتج في مجلد المشروع:

```bash
unzip NOVAADMIN-1.0.0.zip -d novaadmin
cd novaadmin
```

2. ثبّت الاعتماديات:

```bash
npm install
```

3. شغّل بيئة التطوير:

```bash
npm run dev
```

ثم افتح `http://localhost:5173`. ستظهر صفحة المنتج (صفحة الهبوط) ويمكنك الدخول إلى العروض التجريبية منها.

4. ابنِ المخرجات النهائية:

```bash
npm run build
```

تُنشأ المخرجات في مجلد `dist/`؛ وهو المجلد الذي يجب وضعه على الاستضافة.

> ملاحظة: ينفّذ `npm run build` أربع مراحل متتالية: توليد الصفحات من manifest، وتوليد الأصول الرسومية، وحزمة Vite، والترتيب النهائي للمخرجات. لا تشغّل أياً منها يدوياً.

## السكربتات المتاحة

| الأمر | الوظيفة |
| --- | --- |
| `npm run dev` | خادم التطوير مع إعادة التحميل المباشر على المنفذ ٥١٧٣ |
| `npm run build` | بناء كامل للمخرجات في `dist/` |
| `npm run preview` | معاينة المخرجات المبنية |
| `npm run gen:pages` | توليد الصفحات من manifest فقط |
| `npm run gen:assets` | توليد الشعار والصور الرمزية وصور المنتجات وشعارات العلامات |
| `npm run gen:nav` | توليد `navigation.js` و`sitemap.xml` و`robots.txt` |
| `npm run gen:all` | مراحل التوليد الثلاث أعلاه |
| `npm run qa:links` | ضبط جودة المخرجات (الروابط، الأصول، CSS، إمكانية الوصول) |
| `npm run qa:smoke` | تشغيل فعلي للمتحكمات داخل DOM محاكى |
| `npm run qa:all` | البناء + فحصا الجودة |
| `npm run package` | بناء الحزمة النهائية القابلة للتسليم |

## التثبيت على استضافة مشتركة (دون Node)

1. ارفع مجلد `html/` من حزمة المنتج كاملاً.
2. تأكد من أن الملف `index.html` في جذر النطاق.
3. إذا كان الموقع يعمل في مجلد فرعي (مثل `example.com/admin/`)، فجميع الروابط نسبية وتعمل دون تغيير.

> تحذير: لا تعدّل ملفات القالب مباشرة عبر FTP. عدّل دائماً في مشروع المصدر وشغّل `npm run build` مجدداً؛ وإلا ستضيع تغييراتك في البناء التالي.

## استكشاف الأخطاء السريع

- **المنفذ ٥١٧٣ مشغول:** `npm run dev -- --port 5180`
- **توقف التثبيت بخطأ:** `npm cache clean --force` ثم `rm -rf node_modules package-lock.json && npm install`
- **الخطوط لا تُحمّل:** يجب أن تكون الاعتمادية `vazirmatn` داخل `node_modules`؛ وفي المخرجات النهائية تُنقل الخطوط إلى `assets/fonts/`.
- مزيد من الأسئلة ← [استكشاف الأخطاء](troubleshooting.html)
