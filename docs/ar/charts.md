# المخططات

جميع المخططات مبنية على ApexCharts ولها مظهر مشترك: ألوان من الرموز النشطة، وخط Vazirmatn، واتجاه من اليمين إلى اليسار تلقائي، وإعادة بناء عند تغيير السمة.

## الاستخدام التصريحي

```html
<div class="chart" data-chart-key="revenue" data-chart="area" data-chart-height="320"></div>
```

يجلب متحكم الصفحة البيانات من طبقة الخدمات ويمررها إلى `initCharts(root)`. ولإنشاء مخطط يدوياً، مرّر `data-chart-series` بصيغة JSON:

```html
<div class="chart"
     data-chart="column"
     data-chart-height="300"
     data-chart-series='[{"name":"المبيعات","data":[120,180,140,210]}]'
     data-chart-labels='["فروردين","أرديبهشت","خرداد","تير"]'></div>
```

## الاستخدام البرمجي

```js
// الخيار ١ — مباشرة على عنصر
import { createChart } from './js/core/charts.js';

await createChart(document.querySelector('#revenue'), {
  type: 'area',
  height: 320,
  series: [{ name: 'الإيراد', data: [42, 58, 51, 74] }],
  labels: ['فروردين', 'أرديبهشت', 'خرداد', 'تير'],
});

// الخيار ٢ — من داخل متحكم الصفحة بالمساعد `kit.chart`
import { chart } from './js/pages/kit.js';

container.innerHTML = chart({ key: 'revenue', type: 'area', height: 320, series: [{ name: 'الإيراد', data: [42, 58, 51, 74] }], labels: ['فروردين'] });
initCharts(container);
```

## الأنواع المدعومة

| النوع | الاستخدام المقترح |
| --- | --- |
| `area` | اتجاه الإيراد والزيارات |
| `line` | مقارنة سلسلتين زمنيتين |
| `column` | مقارنة الفئات، المبيعات الشهرية |
| `bar` | ترتيب أفقي (منتج، خبير) |
| `donut` | الحصة (جهاز، خطة، مصدر زيارات) |
| `pie` | توزيع بسيط |
| `radar` | مقارنة عدة مؤشرات |
| `radialBar` | تقدّم مؤشر واحد |
| `heatmap` | نمط ساعي/يومي |
| `sparkline` | مخطط مصغّر داخل البطاقة الإحصائية |

## الألوان والسمة

تُقرأ اللوحة من الرموز `--nv-chart-1…6`؛ لذا تتغير المخططات أيضاً عند تغيير `data-primary` أو التبديل بين الفاتح والداكن.

```js
import { refreshCharts } from './js/core/charts.js';
refreshCharts();   // بعد تغيير السمة أو اللغة
```

تلقائياً تُطلق الوحدة `theme.js` حدث تغيير السمة ويعيد `charts.js` بناء جميع مخططات الصفحة؛ ولا حاجة إلى شيفرة إضافية.

## تنسيق الأعداد وتسميات التقويم

تستخدم المحاور والتلميحات `numbers.js`: فواصل آلاف محلية، وأعداداً مختصرة (`formatCompact`) ونسباً مئوية محلية. وتتبع التسميات الزمنية التقويم النشط (هجري شمسي أو ميلادي).

## الأداء

- لا تُنشأ المخططات إلا عندما تكون حاويتها في الصفحة (`initCharts` يعمل على `[data-chart-key]`).
- عند تغيير حجم النافذة، يُعاد تحجيم المخطط دون إعادة بنائه.
- في الصفحات الثقيلة، لا تنشئ المخططات داخل تبويبات مخفية؛ استدعِ `initCharts(panel)` بعد إظهار التبويب.

> ملاحظة: لحذف مخطط قبل إعادة بنائه، استدعِ `chartInstance.destroy()`؛ يحتفظ `charts.js` بالنسخ في `WeakMap` لتجنّب تسرب الذاكرة.

> تحذير: حجم الحزمة `vendor-charts` نحو ٥٤٠ كيلوبايت ولا تُحمَّل إلا في الصفحات التي تحتوي على مخططات (تقسيم الشيفرة مع Vite). لا تضفها إلى الصفحات الخالية من المخططات.
