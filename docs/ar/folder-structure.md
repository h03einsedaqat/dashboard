# بنية المشروع

تقوم بنية المشروع على قاعدة واحدة: **فصل الملفات المولّدة عن المكتوبة يدوياً.** كل ما تنتجه الأدوات يذكر أيضاً في أعلى ملفه أنه لا يجوز تعديله يدوياً.

```text
novaadmin/
├── index.html                     صفحة المنتج (الهبوط)
├── vite.config.js                 نقاط الدخول، الأسماء المستعارة، الأجزاء وإضافات المشروع
├── package.json                   السكربتات والاعتماديات مثبّتة الإصدار
├── public/                        أصول تُنسخ دون معالجة
│   ├── assets/{logo,logo-mark,favicon}.svg
│   ├── assets/img/{avatars,products,brands}/
│   ├── site.webmanifest
│   ├── robots.txt                 يولّده gen-nav
│   └── sitemap.xml                يولّده gen-nav
├── src/
│   ├── pages/**                   ٢٠٦ صفحات مولّدة (الهيكل + موضع المحتوى)
│   ├── partials/                  أجزاء مشتركة
│   │   ├── head.html              الوسوم الوصفية، الخطوط، رابط الأنماط
│   │   ├── header.html            ترويسة التطبيق (البحث، الإشعارات، الملف الشخصي)
│   │   ├── overlays.html          لوحة الأوامر، الاختصارات، حاوية الرسائل
│   │   ├── customizer.html        درج تخصيص المظهر
│   │   ├── footer.html            التذييل
│   │   ├── scripts.html           نقطة دخول JS
│   │   ├── docs/*.html            محتوى الوثائق (يولّده gen-docs من docs/)
│   │   └── pages/<المسار>.html    إعادة كتابة يدوية لمحتوى أي صفحة (اختياري)
│   ├── scss/
│   │   ├── main.scss              الترتيب الدقيق لعمليات الاستيراد
│   │   ├── base/                  رموز التصميم، لوحات الألوان، السمات، إعادة الضبط، الخطوط، جسر Bootstrap
│   │   ├── layout/                الهيكل، الشريط الجانبي، الترويسة، رأس الصفحة، الوثائق، المصادقة
│   │   ├── components/            ٢٨ ملف مكوّن (زر، نموذج، بطاقة، جدول، كانبان…)
│   │   ├── pages/                 تراكيب خاصة بالصفحات (الهبوط، الفاتورة، اللوحة)
│   │   └── utilities/             فئات مساعدة تأتي في النهاية
│   ├── js/
│   │   ├── main.js                المُشغّل: السمة ← التخطيط ← الهيكل ← مسار الصفحة
│   │   ├── core/                  ٢٠ وحدة نواة (دون اعتماد على صفحة بعينها)
│   │   └── pages/                 متحكم لكل قسم، بتحميل كسول
│   ├── services/                  طبقة البيانات بعقد REST
│   ├── data/                      بيانات نموذجية واقعية
│   ├── locales/                   قواميس fa/en/ar + بيانات مولّدة
│   └── config/config.js           إعدادات العلامة، القيم الافتراضية، العملة، المنطقة الزمنية
├── docs/                          ٢٣ مصدر Markdown للوثائق
└── tools/
    ├── manifest.mjs               المصدر الوحيد للتنقل وقائمة الصفحات
    ├── build-pages.mjs            توليد الصفحات + بيانات اللغات
    ├── gen-assets.mjs             توليد ملفات SVG للشعار والصور الرمزية والمنتجات والعلامات
    ├── gen-nav.mjs                navigation.js + sitemap + robots
    ├── gen-docs.mjs               Markdown ← محتوى الوثائق
    ├── flatten-dist.mjs           الترتيب النهائي للمخرجات
    ├── qa-links.mjs               ضبط جودة المخرجات
    ├── smoke.mjs                  تشغيل المتحكمات في DOM محاكى
    ├── package.mjs                بناء الحزمة النهائية
    └── nova-plugin.mjs            إضافة Vite (include، الرموز، المسارات النظيفة)
```

## قواعد مهمة

- **لا تعدّل `src/pages/**`.** تُعاد كتابته في كل بناء. لتغيير محتوى صفحة، أنشئ ملفاً بالاسم نفسه في `src/partials/pages/`.
- **الملفان `src/locales/generated.js` و`src/data/navigation.js` مولّدان.** مصدرهما `tools/manifest.mjs` و`docs/`.
- **تُنسخ الأصول في `public/` دون معالجة.** إذا أردت أن يحسّن Vite صورة ما، فاستوردها من `src/`.
- **كل ما في `src/` يُرسل إلى المتصفح؛** لا تضع ملفات الأدوات أو الوثائق هناك.

## خريطة وحدات النواة

| الوحدة | المسؤولية |
| --- | --- |
| `dom.js` | المحددات، العرض، الأحداث، أدوات الفئات |
| `theme.js` | السمة، لوحة الألوان، التخطيط، الكثافة، حجم الخط، نمط الشريط الجانبي |
| `layout.js` | الهيكل، الشريط الجانبي، وضع الهاتف، التخطيط بعمودين |
| `chrome.js` | لوحة الأوامر، الاختصارات، الإشعارات، محرر الأدوات، المخصِّص |
| `datatable.js` | جدول بيانات كامل (بحث، فلترة، ترتيب، أعمدة، تحديد، تصدير) |
| `charts.js` | مظهر موحّد لـ ApexCharts للوضعين الفاتح والداكن |
| `calendar.js` / `jalali.js` | تقويم الشهر/الأسبوع/اليوم/القائمة وتحويل التاريخ الهجري الشمسي |
| `kanban.js` | لوحة سحب وإفلات بـ SortableJS مع حفظ الترتيب |
| `i18n.js` | اللغة النشطة، `data-i18n`، الاتجاه وإعادة ترتيب النصوص |
| `numbers.js` | الأرقام الفارسية/العربية/اللاتينية، صيغة العملة، الأعداد المختصرة |
| `toast.js` / `modal.js` | الرسائل في أربعة مواضع ونوافذ التأكيد |
| `form.js` / `ui.js` | التحقق، حالات النماذج، التبويبات، الأكورديون، الطباعة |

> ملاحظة: ترتيب التشغيل في `main.js` مهم: `i18n → theme → layout → dropdowns → chrome → forms → ui → route()`. إذا احتاجت وحدة إلى DOM ينشئه متحكم، فيجب استدعاؤها بعد `route()`.
