# الترحيل والتحديث

هذا القسم لحين تحصل على إصدار جديد من القالب وتريد الترقية دون فقدان تغييراتك.

## قبل البدء

1. أنشئ فرعاً في مشروعك: `git checkout -b upgrade/novaadmin-1.1`
2. دوّن قائمة تغييراتك (ما الملفات التي عدّلتها؟).
3. نفّذ `npm run qa:all` على الحالة الحالية للتأكد من سلامة نقطة البداية.

## الملفات التي تُعاد كتابتها في الإصدار الجديد

| المسار | الحالة | التوصية |
| --- | --- | --- |
| `src/pages/**` | مولّد | لا تعدّله أبداً |
| `src/locales/generated.js` | مولّد | لا تعدّله أبداً |
| `src/data/navigation.js` | مولّد | لا تعدّله أبداً |
| `src/partials/docs/*.html` | مولّد من `docs/` | عدّل بدلاً منه `docs/*.md` (و`docs/en` و`docs/ar`) |
| `public/robots.txt`, `public/sitemap.xml` | مولّد | اضبطه في `src/config/config.js` |
| `tools/**` | أدوات | قارن تغييراتك بأداة diff |
| `src/scss/**`, `src/js/**` | مصدر | احتفظ بتغييراتك وادمجها مع الإصدار الجديد |

## طريقة الترقية (خطوة بخطوة)

```bash
# ١. افتح الإصدار الجديد في مجلد منفصل
unzip NOVAADMIN-1.1.0.zip -d /tmp/nova-1.1

# ٢. حدّث الأدوات والأنماط والسكربتات
rsync -av --exclude=node_modules /tmp/nova-1.1/tools/ ./tools/
rsync -av /tmp/nova-1.1/src/scss/ ./src/scss/
rsync -av /tmp/nova-1.1/src/js/core/ ./src/js/core/

# ٣. جدّد الاعتماديات
npm install

# ٤. أعد بناء الصفحات والأصول
npm run gen:all && npm run build

# ٥. ضبط الجودة
npm run qa:all
```

## مقارنة تغييراتك

إذا كنت تدير المشروع بـ git، فأبسط طريقة هي إبقاء تغييراتك في مسارات محدودة:

```text
src/partials/pages/**      محتويات الصفحات المخصصة
src/js/pages/**            المتحكمات المخصصة
src/data/**                بياناتك الحقيقية
src/config/config.js       العلامة والقيم الافتراضية
src/scss/base/_palettes.scss   لوحة ألوان المؤسسة
```

سجّل كل تغيير خارج هذه القائمة في ملف `UPGRADE-NOTES.md` الخاص بمشروعك لتتذكره عند الترقية.

## كيف أكتشف التغييرات الكاسرة؟

| العَرَض | المعنى | الإجراء |
| --- | --- | --- |
| خطأ استيراد في وحدة التحكم | تغيّر اسم ملف أو مساره | اطّلع على الفرق بـ `git log` وصحّح المسار |
| فئة بلا أنماط | حُذفت الفئة أو أُعيدت تسميتها | يعطيك `npm run qa:links` القائمة |
| رمز `{{...}}` في المخرجات | أُضيف رمز جديد | حدّث خريطة الرموز في `tools/nova-plugin.mjs` |
| حركة أو سلوك مزدوج | حُمّلت نسختان من وحدة واحدة | احذف الاستيراد المكرر |

## التراجع

```bash
git checkout -- .
# أو
git reset --hard upgrade/novaadmin-1.0      # إذا أنشأت الفرع قبل الترقية
```

> ملاحظة: قبل كل ترقية نفّذ `npm run build` مرة واحدة واحتفظ بمخرجات `dist/`؛ فإن حدثت مشكلة يمكنك وضع تلك المخرجات على الاستضافة ريثما تفحص الأمر.

> تحذير: لا تُودِع (commit) الملفات المولّدة في git (إلا عند بناء الحزمة النهائية)، وإلا فستواجه تعارضات ضخمة في كل ترقية.
