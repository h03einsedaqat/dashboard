# پرسش‌های متداول

## عمومی

**آیا به بک‌اند نیاز دارد؟**
نه. همه صفحات با داده نمونه کار می‌کنند. برای اتصال به API واقعی بخش [اتصال به API](api-integration.html) را ببینید.

**آیا از React/Vue هم می‌توانم استفاده کنم؟**
قالب خالص HTML/CSS/JS است. می‌توانید باندل را در یک پروژه React هم بارگذاری کنید، اما مزیت اصلی قالب این است که به فریم‌ورک گره نخورده است.

**چند صفحه دارد؟**
۲۰۶ صفحه مستقل (۱۰ داشبورد، ۷۸ اپلیکیشن، ۴۷ جدول فهرست، ۲۱ صفحه UI Kit، ۲۳ مستند، ۱۶ صفحه سیستمی، ۱۱ صفحه احراز هویت) به‌همراه صفحه محصول و صفحه پیش‌نمایش.

**آیا فونت‌ها با مجوز آزاد هستند؟**
بله. فونت Vazirmatn با مجوز SIL OFL و آیکن‌های Bootstrap Icons با مجوز MIT عرضه می‌شوند. جزئیات در [اعتبارها](credits.html).

## ظاهر و تم

**چطور رنگ سازمانی خودم را بگذارم؟**
در `src/scss/base/_palettes.scss` یک پالت جدید بسازید و `data-primary` را روی آن تنظیم کنید. بخش [شخصی‌سازی تم](theme-customization.html) را ببینید.

**چطور لوگو را عوض کنم؟**
فایل `public/assets/logo.svg` (و نسخه‌های `logo-dark.svg` و `logo-mark.svg` و `favicon.svg`) را با طرح خودتان جایگزین کنید؛ نام‌ها را تغییر ندهید.

**حالت تاریک برای همه کامپوننت‌ها کار می‌کند؟**
بله. تم تاریک با توکن‌ها ساخته شده، نه با بازنویسی کامپوننت‌ها؛ پس هر جزء جدیدی هم که با توکن بسازید خودکار پشتیبانی می‌شود.

**چطور تراکم یا اندازه فونت را عوض کنم؟**
از پنل شخصی‌سازی یا `theme.set('density', 'compact')` و `theme.set('fontSize', 'lg')`.

## داده و جدول‌ها

**داده‌ها را کجا عوض کنم؟**
فایل‌های `src/data/*.js`. همه از یک مولد با بذر ثابت ساخته می‌شوند (`src/data/rng.js`)، پس خروجی تکرارپذیر است.

**چطور یک جدول جدید بسازم؟**
بخش [جدول داده](data-tables.html) را ببینید؛ با `data-datatable` و `data-resource` در چند خط تمام می‌شود.

**فیلتر و مرتب‌سازی سمت سرور چطور؟**
پارامترهای `page`, `perPage`, `search`, `sort`, `order` و فیلترها در همان درخواست به API می‌روند؛ کافی است بک‌اند آن‌ها را بپذیرد.

## ترجمه و تقویم

**چطور زبان چهارم اضافه کنم؟**
بخش [چندزبانه](localization.html) — یک فایل دیکشنری و یک خط در `index.js`.

**اعداد همیشه فارسی می‌مانند؟**
در زبان فارسی بله. با `theme.set('language', 'en')` ارقام لاتین می‌شوند و جهت هم عوض می‌شود.

**تقویم میلادی را چطور فعال کنم؟**
`theme.set('calendar', 'gregorian')` یا گزینه «تقویم» در پنل شخصی‌سازی.

## ساخت و انتشار

**چرا `npm run dev` روی پورت ۵۱۷۳ اجرا می‌شود؟**
پورت پیش‌فرض Vite است. با `npm run dev -- --port 5180` عوض کنید.

**چرا استایل‌ها در حالت توسعه اعمال نمی‌شوند؟**
لینک استایل در `src/partials/head.html` با `?direct` نوشته شده تا Vite آن را به‌عنوان CSS سرو کند. اگر این پارامتر حذف شود، فایل به‌صورت ماژول JS سرو می‌شود و صفحه بی‌استایل می‌ماند.

**خروجی را کجا آپلود کنم؟**
محتوای `dist/`. بخش [استقرار](deployment.html) را ببینید.

**چطور بسته فروش را بسازم؟**
`npm run package` — یک ZIP استاندارد با پوشه‌های `html/`, `source/`, `documentation/`, `assets/`, `screenshots/`, `changelog/` می‌سازد.

## پشتیبانی

**آیا به‌روزرسانی‌ها رایگان است؟**
دوره پشتیبانی و به‌روزرسانی در فایل `LICENSE.txt` توضیح داده شده است.

**چطور اشکال گزارش کنم؟**
با ایمیل پشتیبانی (`supportEmail` در `src/config/config.js`) و ذکر نسخه، مرورگر و مراحل بازتولید. قبل از ارسال، `npm run qa:all` را اجرا کنید و نتیجه را ضمیمه کنید.

> نکته: پیش از طرح پرسش، بخش [رفع اشکال](troubleshooting.html) را ببینید؛ پاسخ بیشتر مشکلات رایج همان‌جاست.
