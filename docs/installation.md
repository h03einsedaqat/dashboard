# نصب

نصب NOVAADMIN به Node.js نیاز دارد. اگر فقط می‌خواهید **خروجی آماده** را روی هاست بگذارید، نیازی به هیچ ابزاری نیست: پوشه `html/` را در بسته محصول مستقیماً آپلود کنید.

## پیش‌نیازها

| ابزار | نسخه | توضیح |
| --- | --- | --- |
| Node.js | ۱۸ یا بالاتر | فقط برای ساخت و محیط توسعه |
| npm | ۹ یا بالاتر | مدیریت وابستگی‌ها |
| مرورگر مدرن | Chrome / Edge / Firefox / Safari | پشتیبانی از CSS Nesting، `:has()` و ES2022 |

## گام‌به‌گام

1. فایل ZIP محصول را در پوشه پروژه باز کنید:

```bash
unzip NOVAADMIN-1.0.0.zip -d novaadmin
cd novaadmin
```

2. وابستگی‌ها را نصب کنید:

```bash
npm install
```

3. محیط توسعه را اجرا کنید:

```bash
npm run dev
```

سپس `http://localhost:5173` را باز کنید. صفحه محصول (لندینگ) نمایش داده می‌شود و از آنجا می‌توانید وارد دموها شوید.

4. خروجی نهایی را بسازید:

```bash
npm run build
```

خروجی در پوشه `dist/` ساخته می‌شود؛ پوشه‌ای که باید روی هاست قرار بگیرد همین است.

> نکته: `npm run build` چهار مرحله را پشت سر هم اجرا می‌کند: تولید صفحات از manifest، تولید دارایی‌های گرافیکی، باندل Vite و مرتب‌سازی نهایی خروجی. هیچ‌کدام را دستی اجرا نکنید.

## اسکریپت‌های موجود

| دستور | کار |
| --- | --- |
| `npm run dev` | سرور توسعه با بارگذاری زنده روی پورت ۵۱۷۳ |
| `npm run build` | ساخت کامل خروجی در `dist/` |
| `npm run preview` | پیش‌نمایش خروجی ساخته‌شده |
| `npm run gen:pages` | فقط تولید صفحه‌ها از manifest |
| `npm run gen:assets` | تولید لوگو، آواتارها، تصاویر محصول و لوگو برندها |
| `npm run gen:nav` | تولید `navigation.js`، `sitemap.xml` و `robots.txt` |
| `npm run gen:all` | هر سه مرحله تولید بالا |
| `npm run qa:links` | کنترل کیفیت خروجی (لینک، دارایی، CSS، دسترس‌پذیری) |
| `npm run qa:smoke` | اجرای واقعی کنترل‌کننده‌ها در یک DOM شبیه‌سازی‌شده |
| `npm run qa:all` | ساخت + هر دو کنترل کیفیت |
| `npm run package` | ساخت بسته نهایی قابل ارسال |

## نصب روی هاست اشتراکی (بدون Node)

1. پوشه `html/` از بسته محصول را کامل آپلود کنید.
2. مطمئن شوید فایل `index.html` در ریشه دامنه است.
3. اگر سایت در زیرپوشه اجرا می‌شود (مثل `example.com/admin/`)، همه لینک‌ها نسبی هستند و بدون تغییر کار می‌کنند.

> هشدار: فایل‌های قالب را مستقیم با FTP ویرایش نکنید. همیشه در پروژه منبع تغییر دهید و دوباره `npm run build` بگیرید؛ در غیر این صورت تغییرات در ساخت بعدی از دست می‌رود.

## عیب‌یابی سریع

- **پورت ۵۱۷۳ اشغال است:** `npm run dev -- --port 5180`
- **نصب با خطا متوقف شد:** `npm cache clean --force` و سپس `rm -rf node_modules package-lock.json && npm install`
- **فونت‌ها لود نمی‌شوند:** وابستگی `vazirmatn` باید داخل `node_modules` باشد؛ در خروجی نهایی فونت‌ها به `assets/fonts/` منتقل می‌شوند.
